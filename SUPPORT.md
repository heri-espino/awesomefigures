# Support

For installation, API, plotting, and documentation questions, start with
the [README](README.md), [Sphinx documentation](docs/source/index.rst),
[feature inventory](FEATURES.md), and
[publication guide](docs/source/automatic_publication.rst).

- **Reproducible bug:** open a GitHub issue using the bug report template.
  Include Python/Matplotlib/OS versions, a minimal script, observed versus
  expected behavior, and a trace or diagnostic figure.
- **Feature proposal:** use the feature-request template and explain the
  publication or accessibility problem before proposing an API.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security:** use the private process in [SECURITY.md](SECURITY.md);
  avoid public vulnerability disclosures.
- **Scientific citation:** see [CITATION.cff](CITATION.cff).

Repository: https://github.com/awesomefigures/awesomefigures

Support is volunteer-maintained and no response time is guaranteed.
