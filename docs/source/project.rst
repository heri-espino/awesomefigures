Project, citation, and contribution
===================================

AwesomeFigures is an open-source project under the **MIT license**.
The full license text and copyright notice are maintained in the
canonical repository:

- `LICENSE <https://github.com/awesomefigures/awesomefigures/blob/main/LICENSE>`_
- `CITATION.cff <https://github.com/awesomefigures/awesomefigures/blob/main/CITATION.cff>`_
- `CONTRIBUTING.md <https://github.com/awesomefigures/awesomefigures/blob/main/CONTRIBUTING.md>`_
- `CODE_OF_CONDUCT.md <https://github.com/awesomefigures/awesomefigures/blob/main/CODE_OF_CONDUCT.md>`_
- `SECURITY.md <https://github.com/awesomefigures/awesomefigures/blob/main/SECURITY.md>`_
- `SUPPORT.md <https://github.com/awesomefigures/awesomefigures/blob/main/SUPPORT.md>`_
- `CHANGELOG.md <https://github.com/awesomefigures/awesomefigures/blob/main/CHANGELOG.md>`_
- `ATTRIBUTION.md <https://github.com/awesomefigures/awesomefigures/blob/main/ATTRIBUTION.md>`_

If you use AwesomeFigures in research, cite the software using the
repository's `CITATION.cff`; GitHub's citation interface can format the
metadata. Do not use an unverified DOI.

The package's development and publication guidance are documented in
`RELEASING.md <https://github.com/awesomefigures/awesomefigures/blob/main/RELEASING.md>`_.
The main plotting package and optional TeX/PDF publication dependencies
are described in the :doc:`quickstart` and
:doc:`automatic_publication` sections.
